\chapter{Arithmetic Functions}
\intro{
    An arithmetic function is a function $f : \mathbb{N} \to \mathbb{C}$. The most useful ones are multiplicative, and so are determined by their values at prime powers.

    The Dirichlet convolution turns the set of arithmetic functions into a commutative ring, and Möbius inversion lets us move between a function and its sum over divisors. These are the identities behind the Dirichlet series and Euler products of the analytic part (see \cref{thm:euler-product}).
}
