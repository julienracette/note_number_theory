\chapter*{Notation}
We will use the following notation for the asymptotic estimates: We say that $f(x) = O(g(x))$ if $|f(x)| \leq M g(x)$ for a certain constant $M \in \mathbb{R}$. We can also denote the same bound using Vinogradov notation $f(x)\ll g(x)$. We are also using the Hardy's notation $f(x) \asymp g(x)$ whenever $f(x) = O(g(x))$ and $g(x) = O(f(x))$. We say that $f(x) = o(g(x))$ if $\lim_{x \to \infty} \frac{f(x)}{g(x)} = 0$. Finally, we have that $f(x) \sim g(x)$ to say that $\lim_{x \to \infty} \frac{f(x)}{g(x)}=1 $.

Instead of using $\log \log x $, for simplicity, we will write $\log_2 x$. We denote $\pi(x,q,a):=\#\{p\le x: p \equiv a \pmod q\}$.
